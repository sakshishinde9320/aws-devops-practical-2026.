
# AWS DevOps Practical 2026

## Aim
To implement a CI/CD pipeline using AWS CodePipeline, AWS CodeBuild, Amazon S3, and GitHub.

## Tools and Technologies
- GitHub
- AWS CodePipeline
- AWS CodeBuild
- Amazon S3
- HTML

## Project Description
This project demonstrates the automation of building and deploying a simple website using AWS DevOps services.

## Workflow
1. Source code is stored in GitHub.
2. AWS CodePipeline retrieves the source code.
3. AWS CodeBuild executes the build process.
4. The website file is deployed to Amazon S3.

## Result
Successfully demonstrated an automated CI/CD workflow using AWS services.
